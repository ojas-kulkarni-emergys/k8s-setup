1. Start the worker script

Use the invitation command from your administrator on the intended worker. Inspect the downloaded script first. It generates your WireGuard key locally and displays a device code. The dashboard never receives your private key.



2. Authenticate
Sign in to your invited account. Use the same account for another machine; each machine needs its own invitation. First-time registration requires the invitation code and the exact email invited by the administrator. This implementation uses invitation-bound local accounts; GitHub/Microsoft SSO is not configured.


3. Review and authorize the device
Your administrator must then approve the VPN peer. Return to your worker terminal to continue. Network membership alone does not imply firewall isolation.
